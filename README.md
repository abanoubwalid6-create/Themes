# Xiaomi Studio

A clean, bilingual (English/Arabic) hub for the Xiaomi Studio community: themes, updates, wallpapers and channel links in one fast page.

**Live site:** https://abanoubwalid6-create.github.io/Themes/

## What's inside

- Single `index.html` file - no build step, no dependencies, loads instantly
- Dark and light themes, remembered between visits
- Full English/Arabic switch with proper RTL layout, also remembered
- Direct cards for every community channel
- Small FAQ section
- Mobile-first responsive design with reduced-motion support

## Run it

Open `index.html` in any browser, or serve the folder with any static file server. The page is plain HTML, CSS and JavaScript, so it works anywhere, including GitHub Pages.
